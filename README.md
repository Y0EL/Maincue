# 🎱 Billiard Pro App — Sistem Reservasi Premium 2026

**Billiard Pro** adalah aplikasi modern untuk manajemen dan reservasi meja billiard secara *real-time*. Dengan desain *glassmorphism* premium (Light Theme), aplikasi ini memberikan pengalaman *booking* yang elegan, cepat, dan mewah.

---

## ✨ Fitur Utama (Tahap 1)

- **🎨 UI/UX Premium (Light Theme)**: Antarmuka cantik dengan aksen hijau *emerald* (*Billiard Green*) yang mewah.
- **🎱 Pemantauan Meja Real-time**: Lihat ketersediaan meja, status (Available/Playing) langsung dari aplikasi.
- **📅 Sistem Booking Seamless**: Pilih tanggal, durasi, jumlah pemain, dan langsung amankan mejamu.
- **👤 Profil Pengguna**: Pantau *Poin Reward*, saldo akun, dan status keanggotaan VIP.

---

## 🏗️ Arsitektur Teknologi

Dibuat dari hasil perombakan Cimeat AI yang kompleks menjadi sistem reservasi terstruktur:
- **Frontend**: Next.js 15, React 19, Tailwind CSS v4, Framer Motion (Transisi *Premium*).
- **Backend/Database**: Bersiap untuk integrasi Supabase / Python FastAPI (Real-time).

---

---

## 🚀 Cara Menjalankan Frontend

Pastikan berada di folder aplikasi lalu gunakan npm:
```bash
cd app
npm install  # (jika belum menginstal dependensi)
npm run dev
```
Buka [http://localhost:3000](http://localhost:3000) di browser Anda untuk melihat prototipe antarmuka Billiard Pro.
